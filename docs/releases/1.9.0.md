# Claude 切换器 1.9.0

本版为 macOS 增加 Claude / Claude Code 清理入口，并把主窗口分成「首次使用」「日常使用」「受限与清理」三个使用场景。

## 使用入口

- **首次使用**：按安装、环境检查、选择槽位登录的顺序引导；已有资料保留，无需先清理。
- **日常使用**：优先展示当前槽位、待处理项和启动 / 切换按钮，完整 14 项检查可展开；每次启动或切换仍会重新审计。
- **受限与清理**：网络异常先检查环境，官方明确限制提示联系官方支持；可导出脱敏诊断，确定要重置或卸载时再查看清理范围。工具不判断或解除服务端封禁。

## 清理范围与恢复

「清理 Claude / Claude Code」先扫描并展示实际路径，所有范围默认不选。用户可分别选择桌面数据、Claude Code 数据、Claude 桌面程序、原生 Claude Code 程序、账号快照，查看确认清单后输入「移入废纸篓」。

文件只移入 `~/.Trash/Claude-cleanup-*`；移动前写入 `restore-map.json`，可按清单手动恢复。账号快照默认保留。存在活动会话、并发操作、待恢复快照、预览变化或不安全路径时拒绝执行。中途失败会停止后续移动，并显示已处理结果与恢复位置。

npm / Homebrew 安装需通过原包管理器卸载；钥匙串、浏览器登录、外部 `CLAUDE_CONFIG_DIR`、项目内 `.claude`、系统辅助组件不自动清理。清理 Code 数据会涉及本机 A–D 配置、历史、插件及登录资料，请按预览确认范围。

## 升级与验收

本功能需要同步升级 **核心脚本与 App**。首次安装使用 `installer-kit.zip`；仅替换 app-only 包不会更新核心。已有用户按仓库安装说明更新核心，再使用新版界面。

建议验收顺序：

1. 检查三个场景入口；切换场景本身不应执行安装、登录或清理。
2. 展开 14 项检查，核对失败、警告与灰色跳过状态；启动 / 切换前重新检查。
3. 打开清理页，确认默认不选、路径可查、账号快照默认保留；未输入确认文字不能执行。
4. 仅在确认范围后执行清理，核对逐项结果和废纸篓恢复清单。
